# Strict TDD — Incoders Hive

## Mandatory Loop
1. Write or update a failing test first
2. Implement the smallest change that makes it pass
3. Refactor without breaking the green test suite

## Project Discipline
- Run only the smallest relevant test slice first, then broaden.
- Respect `.github/incoders-ai/gates/*.gate.md`.
- Keep provider SDKs behind adapters.
- Sync docs/specs when product behavior changes.
